# Residence 6018 listing site
Static clone of the Royal Framer template (royaltemplate.framer.website) as a single-listing site.
- Local: `python3 -m http.server 4860 --bind 127.0.0.1` then http://127.0.0.1:4860
- Photos: `./prep_images.sh` rebuilds img/l, img/m and img/photos.js from ~/RE-PHOTOS-20261012/01_LISTING_READY (AI-edited files named with AI_ or Twilight get a "Virtually enhanced" label automatically).
- Deploy: `surge . residence-6018.surge.sh`
- Agent facts sourced from anatoliyrubashka.com/profile/meet-anatoliy and coldwellbankerhomes.com agent page. Address, price, sqft, year not published anywhere found: shown as "on request".
